Overview

This dissertation develops a multidimensional machine-learning framework for soil classification from cone penetration test (CPT/CPTU) data. The work combines supervised and unsupervised learning, evaluates raw and normalized CPT measurements, examines the contribution of depth and geological age, and applies data cleaning, balancing, transformation, statistical comparison, and 10-fold cross-validation.

The supervised study evaluates distance-weighted nearest neighbors, boosted decision trees, random forests, artificial neural networks, support vector machines, and a heterogeneous multiple-model predictor. The unsupervised study develops general and case-based soil classifications using kernel k-means and kernel x-means, followed by neural-network models designed to reproduce the derived classes.

The dissertation uses a broad CPT dataset assembled from 179 soundings and serves as the common research foundation for several later publications and public code repositories.

Multiple-model predictor and supervised classification lineage associated with the 2021 Soils and Rocks article.

CPT-Kernel-Clustering
